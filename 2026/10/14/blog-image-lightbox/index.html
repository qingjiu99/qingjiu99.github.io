给博客图片加灯箱：点击放大、左右切换、缩放旋转

发表于2026-10-14|更新于2026-10-22|技术
|总字数:2131|阅读时长:9 分钟|浏览量:

之前那篇《夜深了，发表感悟》发出去之后，我发现一个问题：文章里的图片虽然能正常显示，但点不开放大。整篇日志配了九张图，写完想看清某一张的细节，只能先点开图片再按浏览器快捷键缩放，麻烦得很。

于是在 Butterfly 主题里翻了一圈，发现主题本身就自带灯箱功能，只是默认没开。而且更巧的是，它支持把灯箱的 JS 和 CSS 下载到本地——这一点正好解决了之前随机封面那个坑的同类问题（jsdelivr 在国内慢甚至被墙）。

一、开启灯箱只要一行配置

Butterfly 主题的配置不在站点根目录的 _config.yml，而在同目录的 **_config.butterfly.yml**，这点我一开始也找了半天。

主题对 fancybox 和 medium_zoom 都支持。区别在于 fancybox 是「图集」式灯箱——一篇里有好几张图时会自动组成一个画廊，能左右翻、显示 1 / 3 这种计数、能看缩略图；medium_zoom 则是每张图独立缩放，样式更简单。文章多图的话明显 fancybox 更合适。

二、主题是怎么把图片变成可点击的

这里有个细节值得说清楚：你什么都不用写，主题的 JS 会在运行时自动处理。

页面加载后，主题的 runLightbox 函数会取出正文容器里的所有图片，然后做两件事：

  1. 跳过带 no-lightbox 类的图片；
  2. 对剩下的图片，如果它的父元素还不是链接，就用 <a> 包一层，并打上 data-fancybox="gallery"：

之后点击就变成触发 Fancybox，而不是跳转。这层包装是运行时做的，所以我一开始想找「文章里到底加了什么代码才让图片能点」，在 Markdown 里翻了个遍什么都没找到——答案是根本没写。

顺带一个好处：因为用了 alt 文字当图注，Markdown 里写 ![螺蛳粉](/img/xxx.jpg)，灯箱打开后图片下方就会显示「螺蛳粉」这几个字。所以 alt 值得认真写，它在灯箱里会露出来。

主题的 img:not(.no-lightbox) 选择器会直接跳过它。

三、真正值得做的：把灯箱资源本地化

如果只做第一步，功能确实能用了。但结合之前《为什么随机封面还是会重复》那篇里提到的外网接口问题，我决定把这一步也做掉。

原因很实际：默认情况下，灯箱的 JS 和 CSS 是从 jsdelivr 拉的：

jsdelivr 在国内访问不稳定这件事，前面已经吃过亏了（随机图接口被限流到 429、302 跳转没 Content-Type 被 ORB 拦）。灯箱和随机封面不一样的地方在于：封面挂了顶多是图裂，灯箱挂了整个交互就废了——JS 没加载出来，图片就还是不能点，页面上没有任何报错提示，对读者来说就是「这网站的图片点不动」，很容易被当成站点坏了。

顺带记几个验证时踩的坑，免得下次再摸一遍：

  • 无头模式下按坐标点击容易点空。scrollIntoView 之后再取 getBoundingClientRect，中间懒加载把图片撑高了，坐标就偏了，点下去什么反应都没有。改成直接 element.click() 走真实事件路径更稳。
  • CDP 实例必须用后台任务方式启动，否则命令一结束进程就被回收，连上去直接 ECONNREFUSED。
  • Pages 部署有延迟。push 成功不代表线上立刻更新，我第一次去查灯箱文件是 404，等了三十秒才变成 200。所以部署后验证要先轮询，别急着下结论。
  • 给页面注入的 JS 里不能用中文标识符。写脚本时顺手把返回字段写成 { 图片总数: 3 }，直接 SyntaxError: Unexpected token '-'。字段名老老实实用英文。

五、最后效果

现在打开任意一篇文章，点正文图片就能弹出大图：图片居中、四周遮罩、底部是 alt 图注，左上角显示 1 / 3 的计数，点左右箭头切换，右上角工具栏有放大缩小、旋转、翻页、缩略图和幻灯片播放，按 ESC 关闭。

几组常用的：

点左右箭头、键盘方向键 上一张 / 下一张
鼠标滚轮 缩放
ESC、点遮罩 关闭

小结

整个改动就两处配置：

  1. lightbox: fancybox 打开开关；
  2. 灯箱的 JS/CSS 下载到 source/pluginsSrc/@fancyapps/ui/dist/fancybox/，在 CDN.option 里指向本地。

不用改 Markdown，不用改主题源码，不用装插件——功能本来就在主题里，只是没打开而已。

这也是用开源主题的好处：很多「自定义」其实只要配置对了就自带。回头要是再遇到「这个功能能不能加」，先去主题的 _config.yml 里翻翻 enable / lightbox 这类开关，很多惊喜。
